## 1. Qué datos tratamos

**De quien crea una cuenta (planners, salones, inmobiliarias):** nombre, correo electrónico,
contraseña (guardada cifrada), nombre comercial, logo, color de marca y número de WhatsApp de
contacto.

**De los proyectos que crean nuestros usuarios:** datos de sus eventos y proyectos (nombre del
evento, fecha, número de invitados, nombre del cliente), planos y diseños, y, si el usuario la carga,
la **lista de invitados**: nombre, grupo o familia y, opcionalmente, dieta o alergia.

**De quien abre un enlace compartido sin cuenta:** el nombre y el texto que escriba si deja un
comentario.

**Datos técnicos:** dirección IP, tipo de navegador y registros de uso necesarios para operar y
asegurar el servicio. Usamos almacenamiento local del navegador para recordar preferencias (idioma,
paneles, nombre para comentar) y una cookie de sesión para mantenerte dentro de tu cuenta.

> **Nota para el abogado:** las dietas y alergias pueden considerarse datos de salud (sensibles).

## 2. Para qué los usamos

**Finalidades necesarias:** crear y administrar la cuenta; guardar y mostrar los diseños; generar
enlaces para compartir y sus vistas previas; mostrar al cliente la marca y el WhatsApp del negocio;
recibir comentarios; generar hojas para imprimir (montaje, invitados, meseros); dar soporte; cobrar
el servicio cuando aplique; y cumplir obligaciones legales.

**Finalidades adicionales (se pueden rechazar):** enviar novedades del producto y encuestas de
satisfacción. Para negarte escribe a [CORREO DE PRIVACIDAD].

## 3. Con quién los compartimos

Con proveedores que nos dan infraestructura y que tratan los datos solo para prestar el servicio:
alojamiento y base de datos (Railway, servidores en Estados Unidos), repositorio de código (GitHub) y,
cuando se active, el envío de correos (por definir). No vendemos datos personales.

Las bibliotecas que el navegador descarga (por ejemplo, three.js desde jsDelivr) pueden registrar tu
dirección IP como cualquier sitio web.
